# RealTime Weather

A sleek, modern, mobile-first weather application built with **React**, **Vite**, and **WeatherAPI**.

![RealTime Weather](https://via.placeholder.com/1200x600?text=RealTime+Weather) <!-- Replace with actual screenshot when uploaded -->

## ✨ Features

- **Real-Time Data**: Get current weather, 24-hour forecast, and 7-day extended forecast.
- **Auto-Geolocation**: Automatically detects your city on load.
- **Pure Monochrome Design**: A stunning minimalist UI with light and dark modes.
- **Air Conditions**: Detailed stats on Real Feel, Wind Speed & Direction, Cloud Coverage, and Humidity.
- **Daylight Tracking**: See exactly where the sun is with a dynamic sunrise/sunset progress bar.
- **Smooth Animations**: Temperatures and stats count up smoothly, and cards float interactively.
- **Keyboard Shortcuts**: Press `Ctrl+K` to instantly focus the search bar.

## 🚀 Quick Start

1. **Clone the repo**
   ```bash
   git clone https://github.com/yourusername/RealTime-Weather.git
   cd RealTime-Weather
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Add your API Key**
   Create a `.env` file in the root directory and add your WeatherAPI key:
   ```env
   VITE_WEATHER_API_KEY=your_api_key_here
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
